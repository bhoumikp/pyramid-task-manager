# Pyramid Task Manager

A full-stack task management application built for the Full Stack
Developer technical assessment.

## Tech Stack

### Frontend
- Next.js
- TypeScript
- Tailwind CSS
- shadcn/ui
- dnd-kit

### Backend
- NestJS
- TypeScript
- Prisma
- PostgreSQL
- JWT
- Google OAuth

## Features

- Guest login
- Google authentication
- Task creation and management
- Board and list views
- Drag-and-drop columns
- Task details
- Subtasks
- Comments
- Activity history
- Projects
- Theme switching
- Accent color customization
- Responsive UI
